# Rogue — консольный рогалик на Python

Пошаговая игра в жанре roguelike, реализованная на Python с использованием библиотеки curses. Цель игрока — пройти 21 уровень подземелья, сражаясь с монстрами и собирая сокровища. Каждый уровень генерируется процедурно, что обеспечивает уникальное прохождение.

## О проекте

- Язык: Python 3.10+
- Библиотека рендеринга: curses (на Windows требуется пакет windows-curses)
- Жанр: пошаговый рогалик с элементами RPG
- Управление: клавиатура
- Сохранение: JSON-файлы

## Возможности

- 21 уровень подземелий с процедурной генерацией
- 9 комнат на каждом уровне, соединённых коридорами
- 5 типов противников: зомби, вампир, привидение, огр, змей-маг
- Дополнительный враг Мимик, притворяющийся предметом
- 5 типов предметов: еда, оружие, свитки, эликсиры, сокровища
- Система разноцветных ключей и дверей
- Автоматическая подстройка сложности под игрока
- Полное сохранение и загрузка игровой сессии в JSON
- Таблица рекордов с детальной статистикой
- Туман войны с алгоритмом Ray Casting
- 3D-режим от первого лица на основе Ray Casting

## Архитектура

Проект разделён на три слоя.

### domain — бизнес-логика

Не зависит от curses и JSON.

- `domain/objects/` — сущности:
  - `player.py` — персонаж
  - `enemy.py` — противник
  - `essence.py` — базовый класс для персонажа и противника
  - `backpack.py` — рюкзак
  - `room.py` — комната
  - `hallway.py` — коридор
  - `level.py` — уровень
  - `game_session.py` — игровая сессия
  - `statistics.py` — статистика игрока
  - `enum.py` — перечисления (типы врагов, предметов, ключей, конфигурация генерации)

- `domain/objects/items/` — предметы:
  - `item.py` — базовый абстрактный класс
  - `food.py` — еда
  - `weapon.py` — оружие
  - `scroll.py` — свитки
  - `elixir.py` — эликсиры
  - `treasure.py` — сокровища
  - `key.py` — ключи

- `domain/logic/` — игровая логика:
  - `logic_game.py` — движок игры: ходы, бой, движение врагов, смерть
  - `logic_environment.py` — взаимодействие с предметами: подбор, использование, выброс
  - `level_generator.py` — процедурная генерация уровней, двери и ключи, BFS
  - `difficulty.py` — автобаланс сложности

### presentation — рендеринг curses

- `presentation/map_renderer.py` — 2D-карта, туман войны, панель статуса
- `presentation/renderer_3d.py` — 3D-режим от первого лица, мини-карта
- `presentation/raycasting.py` — алгоритм Брезенхэма и проверка прямой видимости
- `presentation/menu.py` — главное меню
- `presentation/records_view.py` — таблица рекордов
- `presentation/name_input.py` — ввод имени игрока
- `presentation/victory.py` — экран победы

### datalayer — работа с JSON

- `datalayer/save.py` — сохранение и загрузка игровой сессии, работа с рекордами
- `datalayer/deserializers.py` — восстановление объектов из словарей

### Правило архитектуры

Слой domain не импортирует presentation и datalayer. Зависимости идут только в одну сторону: presentation и datalayer используют domain.

## Установка

Требования:

- Python 3.10 или выше
- Windows: `pip install windows-curses`
- Linux/macOS: библиотека curses встроена

## Запуск

Перейти в папку src и запустить:

    cd src
    python main.py


## Управление

### 2D-режим

| Клавиша | Действие |
|---------|----------|
| W, A, S, D | движение |
| H | использовать оружие |
| J | использовать еду |
| K | использовать эликсир |
| E | использовать свиток |
| 1–9 | выбор предмета из списка |
| 0 | снять оружие (при выборе оружия) |
| Q | сохранить и выйти |
| V | переключиться в 3D-режим |

### 3D-режим

| Клавиша | Действие |
|---------|----------|
| W | вперёд |
| S | назад |
| A | поворот налево |
| D | поворот направо |
| V | переключиться в 2D-режим |
| Q | сохранить и выйти |

## Игровые механики

### Персонаж

- Здоровье, максимальное здоровье, ловкость, сила
- Текущее оружие
- Рюкзак: до 9 предметов каждого типа, сокровища хранятся в одной ячейке
- Временные бонусы от эликсиров, постоянные от свитков

### Противники

| Враг | Символ | Особенность |
|------|--------|-------------|
| Зомби | z, зелёный | низкая ловкость |
| Вампир | v, красный | первый удар промах, отнимает максимальное HP |
| Привидение | g, белый | телепорт, высокая ловкость |
| Огр | O, жёлтый | ходит на 2 клетки, отдых и контратака |
| Змей-маг | s, белый | диагональ, усыпляет игрока |
| Мимик | m, белый | притворяется предметом |

### Предметы

| Тип | Символ | Действие |
|-----|--------|----------|
| Еда | b, a, m, f, e | восстанавливает здоровье |
| Оружие | /, \|, T | увеличивает урон в бою |
| Свитки | ? | постоянные бонусы к характеристикам |
| Эликсиры | % | временные бонусы |
| Сокровища | $, *, & | увеличивают счёт |
| Ключи | k | открывают цветные двери |

### Бой

1. Проверка попадания (по ловкости)
2. Расчёт урона (сила плюс оружие)
3. Применение урона

### Туман войны

- Неизведанные комнаты не отображаются
- Просмотренные комнаты видны как стены
- Текущая комната видна полностью
- Для коридоров используется Ray Casting

## Сохранение

- `savegame.json` — текущая игровая сессия (игрок и уровень)
- `records.json` — таблица рекордов по всем попыткам

Оба файла сохраняются в папке `src/datalayer`. При нажатии Q игра сохраняется. Загрузка — через главное меню.
